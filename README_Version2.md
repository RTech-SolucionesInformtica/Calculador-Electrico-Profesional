# Calculador Eléctrico Profesional (AEA)

Estructura lista para abrir en Visual Studio Code.

Instrucciones rápidas:
1. Crea una carpeta (ej. `calculador-aea`) y pega los archivos tal cual en la estructura indicada.
2. Abre la carpeta en Visual Studio Code.
3. Recomendado: instala la extensión "Live Server".
4. Ejecuta Live Server (botón derecho en `index.html` → Open with Live Server) o desde terminal:
   - Python 3: `python -m http.server 5500` y abre `http://localhost:5500`
5. Agrega tramos en el formulario; el resumen y consolidado de cables aparecerá a la derecha.
6. Usa "Exportar Reporte PDF" para generar un PDF limpio (cabecera/controles se ocultan para impresión).
